================================================================================
BASE PATH CALCULATION (from components.js)
================================================================================

The getBasePath() function in components.js dynamically calculates the base 
path based on nesting depth:

  Root (/)                 → BASE = "./"
  One level (/about/)      → BASE = "../"
  Two levels (/blog/posts/article/) → BASE = "../../"

This allows the same components.js to work across all page depths.

All relative links use: ${BASE} prefix
Example: href="${BASE}contact/" becomes "contact/" at root, "../contact/" at depth 1

================================================================================
BASE PATH IN ACTION
================================================================================

From ROOT (index.html):
  ${BASE} = "./"
  ${BASE}contact/ = "./contact/" = /contact/

From /about/:
  ${BASE} = "../"
  ${BASE}contact/ = "../contact/" = /contact/

From /blog/posts/article/:
  ${BASE} = "../../"
  ${BASE}contact/ = "../../contact/" = /contact/
