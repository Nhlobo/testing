## The Challenge

Metro Analytics needed a real-time dashboard to help city planners and businesses understand urban movement patterns, traffic flows, and economic activity — processing millions of data points daily.

## The Solution

We built CityFlow with Vue.js for the frontend and a Python/FastAPI backend, using Redis for real-time data streaming and Docker for containerised, scalable deployment.

### Key Features

- Real-time data visualisation with WebSocket updates
- Predictive analytics using machine learning models
- Custom report builder with PDF export
- Multi-tenant architecture for different departments
- Map-based visualisations with OpenStreetMap

## The Results

CityFlow processes over 2 million data points per day. Decision-making that previously took weeks of manual analysis now happens in real time. The client estimates R800,000 in annual savings from operational efficiency gains.
